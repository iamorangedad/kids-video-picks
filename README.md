## 表格对比与维护

分类页、不推荐页和待核验页均为 Markdown 对比表：**图片、名称、判断、适龄、简介、研判、证据状态、视频链接**。每部一行，按判断强度排序；80像素缩略图可点开放大，长简介与原文年龄可展开，名称下保留原文来源。宽表在小屏幕上可横向滚动。

表格由 `data/catalog.json` 生成，不手工改逐条正文；修改数据后运行（仅需 Python 3.9+，无第三方依赖）：

```bash
python3 scripts/render_wechat_tables.py
python3 scripts/render_wechat_tables.py --check
```

`--check` 会在表格与数据不同步时返回失败。此次仅调整展示格式，不改变既有判断、适龄或核验状态。

## 使用提醒
