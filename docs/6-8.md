# 6–8 岁：故事变长，科学和友谊可以更具体

这一档能看 10–25 分钟的单元剧，也能接受轻微冒险。科学向优先选《Wild Kratts》《神奇校巴》《Cyberchase》。情感和手艺优先选《希尔达》《亚瑟》《小羊肖恩》《罗小黑战记》。国产经典《葫芦兄弟》和《黑猫警长》有真实的伤害和武器，写在各自的“家长注意”里，不是和《亚瑟》同一安全等级。

《小羊肖恩》同时适合学前上沿，完整条目也在 [3–5 岁](3-5.md)。《降世神通》和《怪诞小镇》的 Common Sense Media 年龄是 8+，战争和惊吓更适合放到 [9–12 岁](9-12.md)。
