# 审核方法与边界

[返回首页](../../README.md) · [来源审查](source-quality.md) · [不推荐](not-recommended.md)

公众号部分为 **2026-11-06 的资料与证据初审**；2026-11-10 应使用者要求增加了一轮全网检索，方法仍不是逐片完整观影，也不是对每条学习效果做过实验。公众号来源以使用者提供的文章为准。全网检索的方法、平台入口、未入库项目见[全网检索来源](../web-search-sources.md)。`docs/web-research/` 里的旧稿仍只作历史资料，没有整批并入。

## 先确认作品，再谈好坏

- 分清同名作品、动画/真人重拍、年份、季与上下篇。搜索命中标题相同不够。
- 本轮排除了《月神》对应马来西亚喜剧、《蓝色小考拉》对应2024真人剧、《森林王子》对应1942真人片、《钟楼怪人》对应1923默片等错误匹配。
- 《星际宝贝》已采用2002动画的评测，不套用2025真人版；《狮子王》的2019写实CG版不套给1994版。
- 合集与平台不能用一个分数或一个年龄给所有内容背书。TED-Ed合集、What If、Little Fox、SSS尤其应逐集选择。

## 四档结论

| 档位 | 含义 |
|---|---|
| 强烈推荐 | 在说明的年龄、成人陪看与风险条件下，独立材料对内容优势支持较清楚；不是“零风险”“看了必有效” |
| 推荐 | 有可辨认的优点和对应独立材料，但存在明确的年龄、题材或观看方式条件 |
| 有保留 | 可能有价值，但身份/适龄/学习证据不足，或成人题材、惊吓、陈旧偏见等需要筛选；**不是隐含推荐** |
| 不推荐 | 不适合作为0—12岁儿童的日常优选，尤其存在已核实的成人性、严重暴力或创伤负荷；**不等于否定作品艺术价值** |

必须把“因证据不足而有保留”和“已有证据显示内容有负荷”分开看。第28篇只有片名而未建立作品级证据的条目单独放在[待核验区](pending-article-28.md)，不会因“330部资源全库”而整体变成推荐。

## 证据怎么用

1. **独立儿童内容指南**：以 Common Sense Media 的编辑评测、BBFC具体内容提醒、Raising Children Network 等为资料。它们的年龄是各自语境中的建议/分级，不是中国法定年龄，也不一定彼此一致。卡片明确区分“CSM建议”“编辑暂议”“原文年龄”。
2. **观众评分**：豆瓣和IMDb主要反映主动评分者的审美，存在样本选择、平台和年代差异；不等于儿童安全或学习效果。本轮未取得可可靠核验的每片评分和票数，统一写**未核实**，不复制文章声称的高分，也不凭印象补数。豆瓣详情访问返回403/418；搜索索引只能用于发现身份或疑点，不能冒充实时评分。
3. **奖项**：即使获奖属实，也主要支持艺术成就，不能把奥斯卡/安锡当儿童分龄。《蜗牛回忆录》就是典型。未独立复核的奖项只保留在“原文说法”里，不计作已验证依据。
4. **教育价值**：区分故事带来的讨论机会、编辑认为有教育内容、真正测过的学习迁移。没有研究就不承诺提高智力、自动开口、治愈焦虑或“越看越开窍”。本轮不声称取得所有节目的实验学习证据。
5. **内容强度**：列出独立指南确认的死亡、捕食、性、虐待、武器、烟酒和惊吓，不因可爱画风或“治愈”文案忽略。青春期、少数群体或不同家庭本身不是扣分理由；看的是表达方式、背景和孩子理解准备度。
6. **节奏与刺激**：没有逐镜剪辑、闪烁或声压测量时，不把“过度刺激”“伤脑”作为确定诊断。关注孩子是否能复述、停看后是否平静、是否挤占睡眠与游戏。英语语速、词汇量与儿童适龄是不同维度。

机器可读依据见 [review-sources.json](../../data/review-sources.json)，每条卡片也有来源链接。只记录短元数据和原创中文归纳，不转载整篇独立评测。

## 儿童观看方式

年龄标签不是推荐给婴幼儿常规刷视频。AAP的既有政策强调：18个月以下一般避免娱乐屏幕（视频通话例外）；18—24个月若引入，选优质内容并由成人共看；2—5岁强调限量、优质与共看。其较新的“5C”材料更强调孩子、内容、安抚方式、挤占活动和交流的整体环境。不要让媒体挤占睡眠、户外、玩耍与真实交流，也不采用“连看四小时更有效”的未经证实建议。

- [AAP 2016政策说明，西班牙语版](https://www.healthychildren.org/Spanish/news/Paginas/aap-announces-new-recommendations-for-childrens-media-use.aspx)（背景政策，不冒称2026新规）
- [AAP：幼儿和学前儿童的5C问题](https://www.healthychildren.org/English/family-life/Media/Pages/kids-and-screen-time-5-cs-questions-for-toddlers-and-preschoolers.aspx)

## 链接与图片的证据等级

- **页面返回200不是成功观看**。原先51个所谓观看链接中，很多返回平台通用页面，另有片花和官方介绍。本轮不再把它们统称正版完整正片。
- `video_url` 目前仅保留已识别的官方作品/节目入口，卡片明确写不是已验证正片。无法确认作品、上传者授权或地区可播的旧地址移到 `candidate_video_url`，不放在推荐观看按钮中。完整正片播放实测数为0。
- 新增海报来自已确认作品的独立评测页面，缩小到约600像素宽；旧图原样保留以便审计。相同文章封面用于多部片的情况明确标记，不能当每片真实海报。
- 没有确认海报时使用原创**文字资料卡**，醒目标注“非官方海报”。这保证卡片有图，但绝不等于海报已补齐。海报和剧照版权归原权利人，没有因入库而获得开放授权。

## 还需要完成什么

- 对“有保留/证据不足”的作品锁定版本，补作品级独立指南和真实内容预看；第28篇的大量续集目前仅逐项留档。
- 在豆瓣、IMDb可用时复核分数与票数，并记录访问日期；不补编。
- 验证各地区正版播放、具体集数、付费条件和上传者；不将资源站、网盘或资源包当合法来源。
- 对科学节目更新过时信息；对中文人文纪录核对史料和叙事立场；必要时由熟悉内容的教师或家长试看片。
