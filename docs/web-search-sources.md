# 2026-11-10 全网检索来源

[返回首页](../README.md) · [微信文章来源](wechat-sources.md) · [审核方法](wechat/review-method.md)

应使用者明确要求“全网搜索”适合儿童的优质视频资源，于2026年11月10日（America/Los_Angeles）做了一次有范围的检索与核验。**检索结果不等于自动推荐。** 只把能打开页面、并能引用独立或官方出处的条目写入目录；猜到的、打不开的、无法核对版本的链接一律不用。

本文件记录检索方法、平台入口、新收录与已有重复项。条目正文、判断和适龄以 [catalog.json](../data/catalog.json) 和分类表为准，这里不重复粘贴整篇评测。

## 方法与边界

- 独立依据优先使用 [Common Sense Media](https://www.commonsensemedia.org/) 的作品或频道/网站编辑评测（年龄、星级、保留意见）。编辑评分不是豆瓣/IMDb，也不是学习效果实验。
- 官方入口只收录本轮成功打开（HTTP 200）的节目页、栏目页或官方频道，例如 PBS KIDS、BBC CBeebies、央视网栏目页。**页面能打开不等于已验证完整正片、免费或当前地区可播。**
- 中文资源若只有制作方官方说明、没有独立适龄评测，判断为**有保留**，官方年龄只作为“栏目定位”，并对照儿科媒体使用的既有谨慎原则（尤其是低龄屏幕）。
- 不把一个频道或网站的评分套到每一集；不把 2017 年重制版评分套给 1990 年代原版；不猜测 Netflix 等平台的片号（曾用错误片号试探时会落到完全无关的节目，故全部放弃）。
- 未把 SciShow Kids、Crash Course Kids、Khan Academy Kids 写入目录：前两者目前只在 CSM 的 STEM 频道清单里出现年龄范围，没有单独的作品级评测页；Khan 相关页面本轮触发了验证墙，未能稳定打开。
- 库中已有的《数字积木》《字母积木》《布鲁伊》不新建条目，只在来源中加记本轮检索。

## 提及但未入库的资源

- **SciShow Kids**（https://www.youtube.com/@SciShowKids，已打开）：CSM《YouTube Kids Channels That Promote STEM》一文（合作方 Sensical）将其列为约 5–10 岁科学频道。这是清单级描述，不是单独评测页，故未建条。
- **Crash Course Kids**（https://www.youtube.com/@crashcoursekids，已打开）：同上文列为约 8–10 岁。注意不要和主频道 [Crash Course](https://www.commonsensemedia.org/youtube-reviews/crash-course) 混淆，主频道 CSM 评 **12+**，含性教育、战争、奴隶制和自杀等议题，不适合作为低龄儿童日常频道。
- **Khan Academy Kids**：本轮打开 `learn.khanacademy.org/khan-academy-kids` 与 `khanacademy.org/kids` 均返回验证页，未能核对内容，故不写入目录。
